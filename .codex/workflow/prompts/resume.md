# Resume a task

```text
Select and use the skills mapped to the affected components in AGENTS.md. Also
use $system-design when the task crosses component or bounded-context boundaries.
Continue .codex/workflow/tasks/<task-name>.md within its recorded authorized phase
and the user's latest instructions. Follow AGENTS.md. Check the current
branch, HEAD, staged/unstaged changes, and implementation before trusting the
task summary. Preserve unrelated work.

Resume the next unfinished step. Reuse valid investigation and verification
evidence; repeat a check only when the relevant code or risk changed. Planning
does not become implementation authorization merely because a task exists.

Use coder for bounded authorized edits and investigator/reviewer for
read-only work when useful. Record actual agent activity; do not infer it from
configured role files. Update current state, material decisions, verification
and handoff. Report the outcome and remaining limits.
```
